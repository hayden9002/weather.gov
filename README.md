# weather.gov

This is effectively a mobile port of the webiste weather.gov with a couple goodies added :)

Location storage: the location is kept even when the app is closed
Location serch: scroll down from the top to search for your location


Feel free to add to this project as well the more the merrier!


As for how you get it, you need to well use Xcode and build the app yourself as i dont know how to share it :(
(This app is NOT affilated with the national weather service)
